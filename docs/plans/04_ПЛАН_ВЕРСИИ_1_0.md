# 🧊 План версии 1.0.0 — контракт стабильности

## Назначение

Пакет опубликован на PyPI (0.9.6): каждое изменение публичной поверхности — теперь
чужая боль. Версия 1.0.0 — первый релиз с **публичным обещанием стабильности**:
шесть контрактов замораживаются, все изменения до 2.0.0 — только additive.

## Принятые решения

- **Python floor: остаётся `>=3.9`.** Подъём — только в 2.0, с данными о базе
  юзеров. 1.0 — про стабильность, не про новизну.
- **Эталоны: без утолщения.** 23 документа, оговорки фиксируются в CHANGELOG
  честно (`accuracy_is_real: false`). Утолщение — повестка 1.1.
- **P4.7 не входит.** КПП legal_claims, канон-тест flat_columns, short-circuit
  денежных правил остаются отложенными.

## Замораживаемые контракты (шесть)

1. **Python API** — `LegalDocPlatformFacade`: методы, сигнатуры, типы.
2. **CLI** — подкоманды, флаги, коды возврата `0/1/2/3/4`, `--json`.
3. **JSON-структуры** — `{stem}_Full.json`, `{stem}_Flat.json`,
   `Registry_Full.json`, отчёт верификации (ключи и вложенность).
4. **JSON-RPC stdio** — wire-контракт 5 tools + поле `protocol_version`.
5. **Контракт плагина** `doc_types/` — 7 обязательных файлов +
   `verification.json` + опциональный `flat_1c.json` (точка расширения
   для третьих лиц).
6. **Env-переменные** — `SCANREADER_*` / `VLM_*` / `OPENAI_*`: имена и
   семантика значений.
