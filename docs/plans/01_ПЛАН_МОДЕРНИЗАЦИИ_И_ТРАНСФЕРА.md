### 1. Архитектурные компоненты и структура проекта

```
Версия 7/
├── .env                              # Конфигурация локальной модели (Ollama / vLLM / OpenAI)
├── .env.example                      # Шаблон конфигурации
├── requirements.txt                  # Зависимости Python (pydantic, openai, pillow, pymupdf, openpyxl, pandas, pytest)
├── AGENTS.md                         # Свод инженерных правил для AI-разработчиков
│
├── core/                             # 🏛️ Инфраструктурное ядро (перенесено и адаптировано из QA Agent)
│   ├── __init__.py
│   ├── utils.py                      # Безопасный JSON-парсинг (<think> фильтр), UTF-8, логгер, санитизация
│   ├── token_tracker.py              # Потокобезопасный трекер токенов, latency и скорости (tokens/sec)
│   ├── diagnostics.py                # Самопроверка подключения к Ollama/vLLM/OpenAI, пинг, TTFT
│   ├── rate_limiter.py               # Token Bucket + семафор параллелизма (защита GPU от перегрузки)
│   ├── cache.py                      # Детерминированный SHA-256 кэш ответов (быстрый, без накладных расходов)
│   └── document_loader.py            # Универсальный загрузчик DOCX, DOC, RTF, TXT с автокодировкой
│
├── Исполняемые файлы/
│   ├── type_registry.py              # Реестр плагинов типов документов (3 активных плагина)
│   ├── file_processor.py             # Гибридный процессор (PDF, изображения, офисные документы)
│   ├── facade.py                     # Единый фасад платформы (LegalDocPlatformFacade)
│   ├── excel_exporter.py             # Профессиональный многостраничный экспорт в Excel (openpyxl)
│   ├── launcher.py                   # Интерактивный UI/CLI лаунчер с Drag & Drop и Win32 диалогом
│   └── doc_types/                    # Пакеты плагинов документов:
│       ├── enforcement_orders/       # Приказы и заявления о возбуждении ИП (7 компонентов)
│       ├── executive_documents/      # Исполнительные листы (7 компонентов)
│       └── salary_deductions/        # Постановления о взыскании на заработную плату (7 компонентов)
│
├── data/
│   └── ground_truth/                 # Эталонные разметки для бенчмаркинга
├── Входящие_документы/               # Папки для входящих сканов и файлов
├── Результаты/                       # Папка выгрузки JSON, Markdown и Excel отчетов
├── tests/                            # 🧪 Набор автоматических тестов (pytest - 20/20 ✅)
│   ├── conftest.py
│   ├── test_utils_and_safe_json.py
│   ├── test_type_registry.py
│   ├── test_file_processor.py
│   ├── test_facade_and_mocked_vlm.py
│   ├── test_cache_and_diagnostics.py
│   └── test_excel_exporter.py
│
├── 0_ДИАГНОСТИКА_VLM_И_ТОКЕНЫ.bat    # Диагностика и бенчмарк скорости модели
├── 1_ОБРАБОТКА_ДОКУМЕНТОВ.bat        # Запуск интерактивной обработки (Drag & Drop / Проводник)
├── 2_Открыть_веб_дашборд.bat         # Открытие веб-интерфейса
├── 3_ЗАПУСК_БЕНЧМАРКА_GROUND_TRUTH.bat # Автоматическое тестирование точности по эталонам
└── 4_ЭКСПОРТ_В_EXCEL.bat             # Сборка сводного Excel реестра
```
